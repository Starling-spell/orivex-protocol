GenLayer StudioNet user guide

Submit an agent claim, bind it to immutable evidence, and let validators independently fetch and evaluate it.

Open Agent Lab · Hackathon docs · Live receipts

Verify your own agent

  1. Enter a unique reference ID, exact claim, and testable criterion.
  2. Use immutable HTTPS evidence: raw GitHub URLs must pin a 40-character commit; IPFS gateways are supported.
  3. Fetch and hash the evidence. The SHA-256 must match the exact bytes validators fetch.
  4. Copy the generated CLI payload from the Agent Lab, submit with the StudioNet account, then verify using the returned proof ID.

CLI: npm run genlayer:studio genlayer account use studio-proof-deployer npm run genlayer:check npm run genlayer:publish

Read results

SUCCESS supports the claim. FAILED refutes it. INCONCLUSIVE means evidence is insufficient. Select Recheck onchain to verify the finalized receipt, source, submitter, and proof commitment.

Recovery

URL rejected: use HTTPS and pin a commit or CID. Digest mismatch: hash raw response bytes. Pending: wait for finality. Empty examples: run the commands above.
