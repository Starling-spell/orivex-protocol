Verify your own agent

This page is the runbook. Your generated commands stay on the Agent Lab after you fill the form and hash the evidence.

  1. Return to the Agent Lab and enter a unique reference ID, exact claim, and testable criterion.
  2. Use immutable HTTPS evidence: raw GitHub URLs must pin a 40-character commit; IPFS gateways are supported.
  3. Click Fetch and hash evidence. The SHA-256 must match the exact bytes validators fetch.
  4. Click Copy CLI payload on the same page. The payload uses genlayer write … --args, not genlayer contract write.
  5. Run submit, copy the returned proof ID from the receipt, then run verify. Look the proof up in the Agent Lab by ID.

CLI: npx --no-install genlayer network set studionet npx --no-install genlayer write <address> submit_proof --args … npx --no-install genlayer write <address> verify_proof --args <PROOF_ID>

Read results

SUCCESS supports the claim. FAILED refutes it. INCONCLUSIVE means evidence is insufficient. Select Recheck onchain to verify the finalized receipt, source, submitter, and proof commitment.
